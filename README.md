# Repo_practica200

Repositorio de GitHub para la práctica 2.00 de Acceso a Datos, sobre el patrón Singleton, DAO y repositorios.

## Clonar el repositorio

**Enlace al repositorio:**  
https://github.com/Lorena-Arbe-Sanchez/Repo_practica200

Para clonar el repositorio, ejecuta el siguiente comando:

```bash
git clone https://github.com/Lorena-Arbe-Sanchez/Repo_practica200.git
```

Después, abre en IntelliJ IDEA la carpeta `practica200`, que contiene el proyecto Maven.

## Base de datos

El repositorio incluye el fichero `practica200.sql`, que contiene los datos de la base de datos utilizada en phpMyAdmin.

Para utilizarla, importa el fichero SQL en phpMyAdmin y comprueba que la base de datos esté configurada correctamente antes de ejecutar el proyecto.
